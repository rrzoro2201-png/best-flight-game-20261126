Langit Senja: an original 2D flight game — fly a prop plane through island rings and land on the runway at dusk.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with the arrow keys (or WASD): up climbs, down descends, right adds throttle, left eases off, Space boosts. Fly through the glowing rings in order, watch your fuel, and land on the runway at the end of the sortie. P pauses, R restarts, M mutes.
